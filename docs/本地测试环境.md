# 本地 Web/PWA 测试

## 日常检查

```sh
npm run check
npm test
npm run serve
```

打开 `http://localhost:8080`，检查规划、今日执行、历史、设置和导出备份。开发只需要 Node.js 22+；没有 npm 运行时依赖。

## 数据库回归

安装 PostgreSQL 工具，使 `initdb`、`pg_ctl`、`psql` 位于 PATH，运行：

```sh
npm run test:db
```

脚本在系统临时目录创建独立数据库，仅使用独立 Unix socket。它模拟 Supabase 的 `auth.uid()`，运行真实 v3 SQL 与事务，再关闭并清理临时数据库。不会使用生产环境 URL。

## 浏览器端隔离测试

`tests/support/browser-server.cjs` 是测试专用适配器：页面使用真实 Supabase 浏览器 SDK，登录由本机模拟，RPC 调用实际本地 PostgreSQL。需要显式设置 `SIXTHINGS_TEST_PG_DIR`，可用 `SIXTHINGS_TEST_PG_PORT` 和 `SIXTHINGS_TEST_PORTS` 指定隔离端口。不要把此适配器部署到线上。

使用三个不同本地端口模拟三台设备；开始前确认三个来源没有已有清单，且 `/config.js` 的 URL 都指向当前本地来源。

1. A 生成配对码，B 加入；A 再生成新码，C 加入。
2. A 新增、删除任务和改变设置，B/C 应一致。
3. B 断网并修改，离线重开页面后内容仍在；恢复网络后 A/C 应收到。
4. 两端同时修改不同任务、同一任务不同字段，再检查收敛。
5. 检查手机宽度、离线加载和新版本缓存更新。

项目只维护 Web/PWA，开发与测试无需 Android SDK 或 Xcode。
